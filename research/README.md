# research/ — 도시 데이터의 원자료

`data/<city>.json`에 들어간 숫자·설명이 **어디서 왔는지**를 남기는 자리다. 새 도시를 조사하기 전에 여기부터 본다 — 이미 조사한 도시를 다시 조사하거나, 뺀 곳을 다시 후보에 올리는 일을 막는다.

## 규칙

- 도시마다 폴더 `research/<city>/`. 조사 결과 JSON은 **항목마다 출처 URL**이 있어야 하고, 못 찾은 칸은 `null`(추측 금지).
- `data/<city>.json`의 장소마다 `src`가 붙는다: `coord`(좌표 출처 — OSM·Wikipedia·Wikidata), `refs`(설명·영업시간·요금의 출처 URL), 있으면 `dwell`(체류 선택지 분의 근거가 된 투어 상품), `package`(패키지 상품 몇 개에 나왔나). 위키데이터로 만든 도시(런던·파리·도쿄…)는 `q`(Wikidata id)가 좌표·이름의 출처다.
- 도시 파일 맨 아래 `sources`에 조사 날짜·파일 목록·**뺀 곳과 이유**를 적는다. 다음에 "왜 보홀이 없지?"를 다시 조사하지 않게.
- 조사는 Sonnet/Opus 세션에 맡기고, 결과가 오면 데이터에 들어간 숫자 3건을 골라 원문을 다시 열어 대조한다(표본 재열람). 통과한 조사만 여기 넣는다.
