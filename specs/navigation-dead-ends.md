# 이동·뒤로 가기 테스트 계획 — 막히는 화면 찾기

작성 2026-11-02 · 대상 `http://localhost:8080/?local=1` (브라우저 저장 모드: 로그인 없이 「내 여행」, 이름 적고 「시작」)
범위: 일정 만들기(플랜) → 목록(내 여행) → 상세(여행) → 구간 플랜, 그리고 계정·문서·404·휴대폰 폭.
원칙: 화면 이동(탭·여행 열기)은 브라우저 기록에 쌓이고, 플랜 편집(장소 담기 등)은 기록에 안 쌓이고 「↶ 되돌리기」로 되돌린다 — 이건 의도다. 각 화면에서 **돌아갈 수단 셋**(화면 안 버튼·상단 탭·브라우저 뒤로)을 따로 본다.

공통 시작 상태: 새 탭, `localStorage.clear()` 뒤 `/?local=1#tab=home`. `window.prompt`를 쓰는 버튼(「지금 플랜으로 새 여행」)은 dialog를 받아 이름을 넣는다.

---

## 발견한 문제 (탐색 중 실제로 재현됨 — 고치지 않음)

### P1. 「← 여행」이 앞으로 가는 기록을 하나 더 쌓아 뒤로 가기가 핑퐁이 된다
1. 내 여행 → 「시작」 → 「지금 플랜으로 새 여행」(이름 입력) → 여행 상세
2. 「플랜 열기」 → 구간 플랜 → 「← 여행」 → 여행 상세
3. 브라우저 뒤로 → **구간 플랜**이 다시 열린다 → 뒤로 → 여행 상세 → 뒤로 → 목록
- 기대: 「← 여행」 뒤의 브라우저 뒤로는 목록(또는 상세에 들어오기 전 화면)으로 간다.
- 실제: 상세 ↔ 플랜을 오간 횟수만큼 뒤로를 더 눌러야 목록에 닿는다.

### P2. 계정 화면은 기록에 안 쌓여서 뒤로 가기가 목록을 건너뛴다
1. 내 여행 목록(`#tab=mine`) → 오른쪽 위 이름 버튼 → 「내 계정」
2. 브라우저 뒤로
- 기대: 내 여행 목록
- 실제: **홈**(목록 이전 화면)으로 간다. 주소가 계정에서도 `#tab=mine` 그대로라 새로고침하면 계정이 아니라 목록이 나온다.

### P3. 계정 화면을 뒤로 가기로 벗어나면 「계정 열림」이 남아, 나중에 「내 여행」이 계정을 연다
1. P2의 1~2 (계정 → 뒤로)
2. 다른 화면에서 「내 여행」으로 가기 (예: 없는 여행 404의 「내 여행」 버튼, 또는 상단 「내 여행」 탭)
- 기대: 내 여행 **목록**
- 실제: **「내 계정」** 화면이 뜬다.

## ① 만들기 → 목록 → 상세

### 1-1. 홈 도시 카드 → 플랜 → 돌아가기
- 단계: 홈에서 「런던」 카드 → 플랜(노선도) 화면
- 기대: 상단 탭 「홈」이 보이고 눌러서 홈으로 간다. 브라우저 뒤로도 홈. 화면 안에는 전용 뒤로 버튼이 없다(탭이 대신함) — 이게 맞는지 디자인 판단 필요로 기록.
- 실패: 뒤로가 홈이 아닌 곳, 또는 두 번 눌러야 홈.

### 1-2. 플랜에서 장소 담기는 기록에 안 쌓인다
- 단계: 플랜에서 1순위 칩 3개 담기 → 브라우저 뒤로
- 기대: 담기 전 플랜이 아니라 **홈**으로 간다. 담은 걸 되돌리려면 「↶ 되돌리기」/⌘Z.
- 실패: 뒤로가 장소를 하나씩 빼며 플랜에 머문다.

### 1-3. 로그아웃 상태로 「여행으로 저장」
- 단계: 로그인 없이 플랜에서 장소 1개 → 「여행으로 저장」
- 기대: 내 여행 로그인 화면으로 가고, 플랜은 주소에 그대로 남는다(장소 유지). 뒤로 → 플랜(장소 그대로).
- 실패: 장소가 사라지거나, 뒤로가 플랜으로 안 돌아온다.

### 1-4. 목록에서 새 여행 → 상세 → 목록
- 단계: 내 여행 → 「시작」 → 「지금 플랜으로 새 여행」(prompt) → 상세 → 「← 내 여행」
- 기대: 상세 맨 위 「← 내 여행」이 보이고 목록으로 간다. 이어서 뒤로 → 상세, 다시 뒤로 → 목록.
- 실패: 길잡이가 화면 밖에 있거나, 목록 대신 홈으로 간다.

### 1-5. 「플랜 링크로 여행 만들기」 → 상세
- 단계: 목록 → 「플랜 링크로 여행 만들기」 펼치기 → 플랜 링크 두 줄 붙여 넣기 → 「여행 만들기」
- 기대: 상세로 가고 구간 알약(도시 둘). 뒤로 → 목록(펼친 칸은 접혀도 됨).
- 실패: 뒤로가 같은 상세에 머문다.

### 1-6. 상세 새로고침
- 단계: 상세에서 주소 그대로 새로고침
- 기대: 같은 여행 상세, 고른 구간은 첫 구간으로 돌아와도 됨(화면 상태). 「← 내 여행」 그대로.

## ② 상세 ↔ 구간 플랜

### 2-1. 「플랜 열기」 → 「← 여행」 → 뒤로 (P1 재현 시나리오)
- 기대/실패: P1 참조. 수정 후엔 「← 여행」 다음 뒤로가 목록에 닿아야 통과.

### 2-2. 두 번째 구간 플랜
- 단계: 구간 둘인 여행 → 구간 알약 「파리」 → 「플랜 열기」 → 플랜 머리의 구간 알약 「런던」 → 「← 여행」
- 기대: 상세로 돌아오고, 고친 구간만 저장 반영. 뒤로 순서가 화면 이동 순서와 같다.
- 실패: 다른 구간 플랜이 열리거나, 뒤로가 구간 사이를 맴돈다.

### 2-3. 일차 알약·접기는 기록에 안 쌓인다
- 단계: 상세에서 「2일차」 알약, 1일차 접기 화살표 → 브라우저 뒤로
- 기대: 상세 이전 화면(목록)으로 간다(알약·접기는 화면 상태).
- 실패: 뒤로가 알약 선택을 하나씩 되돌린다.

### 2-4. 뒤로 → 앞으로 왕복
- 단계: 목록 → 상세 → 구간 플랜 → 뒤로 → 뒤로 → 앞으로 → 앞으로
- 기대: 같은 여행·같은 구간 플랜으로 정확히 돌아온다.

## ③ 계정·문서·404

### 3-1. 계정 화면 돌아가기 (P2·P3)
- 화면 안: 「내 여행 목록」 버튼 → 목록. 상단 탭 → 각 탭. 브라우저 뒤로 → **목록이어야 함**(현재 실패).
- 이어서 상단 「내 여행」 탭 → 목록이어야 함(현재 P3로 실패할 수 있음).

### 3-2. 개인정보처리방침·이용약관
- 단계: 홈 아래 「개인정보처리방침」 → 뒤로 / 페이지 아래 「홈」 링크 / 「이용약관」 링크
- 기대: 뒤로 → 홈. 쪽 아래 링크 셋이 모두 동작. 상단 탭도 보임.

### 3-3. 없는 화면 404
- 단계: `#tab=아무거나` 열기
- 기대: 「이 역은 없어요」 + 「홈으로」·「내 여행」. 둘 다 동작하고, 뒤로 → 직전 화면.

### 3-4. 없는 여행 404
- 단계: 로그인 상태에서 `#tab=mine&pr=nonexist`
- 기대: 「이 여행은 노선에 없어요」. 「내 여행」 → **목록**(P3면 계정이 뜸 — 실패). 뒤로 → 404 다시(정상).

### 3-5. 잘못된 경로
- 단계: `/route-planner/없는주소` (배포본) 또는 로컬 `/nope`
- 기대: 404.html → 앱의 「이 역은 없어요」로 넘어감. 뒤로가 404.html로 되돌아가 다시 넘기는 고리가 없을 것.
- 주의: 로컬 정적 서버(python http.server)는 404.html을 안 쓴다 — 배포본에서만 확인.

### 3-6. 로그인 세 역 (`?local=1` 없이)
- 단계: 내 여행 → 「회원가입」 역 → 「비밀번호 찾기」 역 → 브라우저 뒤로
- 기대: 세 역 전환은 화면 상태라 뒤로는 내 여행 이전 화면으로 간다. 「로그인」 역으로 돌아올 수단은 항상 보임.

## ④ 휴대폰 폭 (375×812)

### 4-1. 화면별 돌아갈 수단이 첫 화면에 보이는가
- 대상: 플랜, 여행 상세, 구간 플랜, 계정, 약관, 404
- 기대: 상단 탭 줄이 가로로 넘치지 않고(가로 스크롤 0), 「← 내 여행」·「← 여행」이 스크롤 없이 보인다.
- 실패: 길잡이가 지도 아래로 밀려 스크롤해야 보인다(휴대폰은 지도가 위 68vh) — 특히 구간 플랜·여행 상세.

### 4-2. 휴대폰 뒤로 제스처 = 브라우저 뒤로
- 단계: ①·②의 흐름을 375 폭에서 반복
- 기대: 데스크톱과 같은 순서.

- 지금 상태: P1·P2·P3 세 곳이 실패. 나머지는 탐색 중 정상(1-1·1-3·1-4·3-2·3-3 일부를 직접 확인). 4번(휴대폰)과 3-5(배포본 404)는 탐색하지 않음.
