# AlgoTrip 이동·뒤로 가기 테스트 계획 (막다른 화면 점검)

## Application Overview

AlgoTrip(정적 사이트, 해시 라우팅)의 화면 이동과 뒤로 가기를 점검하는 계획. 모든 시나리오는 http://localhost:8080/?local=1 로 시작하고, 시작 상태는 빈 브라우저 저장(localStorage·sessionStorage 비움)이다. 「내 여행」 첫 화면에서 이름을 적고 「시작」을 눌러야 로그인된다. 화면 이동(탭·여행 열기·← 길잡이)은 브라우저 기록에 쌓이고, 플랜 편집·일차 알약·접기는 쌓이지 않는 것이 의도다.

## 발견한 문제 (탐색 중 확인, 고치지 않음)

각 항목은 로컬 모드(?local=1)에서 직접 재현한 것이다.

1. [걸림-낮음] 여행 상세에서 상단 「내 여행」 탭이 아무 일도 하지 않는다. 재현: 로그인 후 여행을 하나 만들어 상세(#...&tab=mine&pr=<id>)를 연다 -> 상단 「내 여행」 탭을 누른다 -> 주소와 화면이 그대로 상세다. 목록으로 가는 수단은 「← 내 여행」과 브라우저 뒤로뿐이다. 구간 플랜(#...&pr=<id>, tab 없음)에서 「내 여행」 탭을 누르면 목록이 아니라 그 여행 상세로 간다. 의도인지 확인 필요.
2. [혼동] 홈 탭으로 나가도 주소에 pr=<id>가 남는다. 재현: 구간 플랜(pr 있음) -> 상단 「홈」 -> 주소가 #...&tab=home&pr=<id>. 이 상태에서 「플랜」 탭을 누르면 홈 이전의 구간 플랜(pr 유지)으로 돌아가고, 「내 여행」 탭을 누르면 목록이 아니라 그 여행 상세가 열린다. 새 도시 카드(예: 도쿄)를 누르면 pr이 지워지는 것은 정상. 홈을 거친 뒤 「내 여행」이 목록을 안 보여 주는 점이 혼동 소지.
3. [새로고침] 계정 화면은 주소가 #tab=mine 으로 「내 여행 목록」과 같아서, 계정 화면에서 새로고침하면 계정 화면이 아니라 내 여행 목록이 뜬다. 또 계정 화면의 「내 여행 목록」 버튼은 주소가 그대로라 기록이 쌓이지 않는다(뒤로 가면 계정이 아니라 그 전 화면인 홈으로 감). 화면 이름이 주소에 안 담기는 구조.
4. [휴대폰 폭] 375x812에서 존재하지 않는 여행(#tab=mine&pr=nonexist)의 404 「홈으로」 버튼이 y=957로 화면 밖에 있다(스크롤 필요). 위에 지도 영역이 같이 그려지기 때문. 상단 탭 「홈」은 y=61에 보이므로 완전히 막힌 것은 아니다. 같은 폭에서 상세의 「← 내 여행」(y 726~764)과 구간 플랜의 「← 여행」(y 752~782)은 화면 아래쪽 가장자리 근처라 위치가 낮다(스크롤 없이 보임).

문제 아님으로 확인한 것: 상세 -> 「← 내 여행」 -> 뒤로/앞으로 왕복이 정확히 이전 화면으로 돌아감(핑퐁·중복 없음). 상세 <-> 구간 플랜의 「플랜 열기」/「← 여행」, 뒤로, 앞으로, 새로고침 모두 같은 화면 유지. 404(모르는 탭·없는 여행)에서 「홈으로」/「내 여행」/뒤로 정상. 개인정보·이용약관은 상단 탭과 하단 「홈」으로 나갈 수 있음. 주의: 화면 안 칩은 숨은 접힘 블록 안의 label이라 자동화 시 details를 먼저 열어야 하고, 「지금 플랜으로 새 여행」의 window.prompt는 click 전에 dialog 핸들러를 등록해야 한다.
