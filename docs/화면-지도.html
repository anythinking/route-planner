알고트립 화면 지도

가고 싶은 곳을 고르면 며칠에 어떻게 나누고 하루에 어떤 순서로 돌지 계산해 주는 사이트다. 로그인 없이도 플랜을 끝까지 짤 수 있고 그때는 주소(링크)가 곧 저장이다. 로그인하면 플랜이 「여행」으로 쌓이고 살 것 · 사진 · 공유가 붙는다.

도시 고르기→장소 담기→날로 나누기→여행으로 저장→공유
화면 틀을 누르면 그 화면에 닿는 선만 남는다. 판은 끌어서 옮긴다.
화면 이동 저장한 것이 흘러감 이어져야 하는데 없음

화면별 목적

2026-11-14 기준. 화면 주소와 화면 사이 이동은 코드에서 읽었다. 틀 안의 그림은 이 맥에서 브라우저 저장 모드로 실제 화면을 찍은 것이고(런던, 12곳, 3일), 로그인 화면만 실제 계정 서버 쪽 화면이다. 공유 칸은 로그인해야 열려서 약도를 넣었고, 빨간 점선 틀은 꺼 두었거나 아직 없는 화면이다.
